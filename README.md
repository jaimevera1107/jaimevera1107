## Featured Projects

### [`tempdisagg`](https://github.com/jaimevera1107/tempdisagg)
A Python library for temporal disaggregation. It expands on existing approaches by providing:
- Econometric models and ensemble methods  
- Robust adjustments for irregular structures and outliers  
- Handling of negative values  
- Interpretable summaries and built-in visualization tools
